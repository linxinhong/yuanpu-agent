# 工作会话文件夹树 v003

用户确认的界面方案沿用现有全宽顶栏：左侧导航栏位于顶栏下方，展开后显示文件式会话树；右侧文件预览与面板拖宽保持现有布局。工作树使用 Yuanpu 图标、主题颜色和紧凑工具栏，没有新的项目实体。文件夹可任意嵌套，会话是一棵树中的叶节点。

每个节点用稳定 ID 操作。单击打开，折叠箭头控制子树；双击或行菜单重命名。工具栏新建会话、文件夹并提供搜索；行菜单设置内置图标和多个标签、归档/恢复、移动到文件夹。拖放与“移动到”调用同一服务端迁移，搜索期间禁用移动，失败时刷新服务端树。面包屑显示当前会话的文件夹路径。搜索按文件夹、标题、标签和 Pi 消息返回结果，消息结果用 entryId 打开历史窗口并滚动定位。

活动 Work run 或待审批期间，服务端拒绝切换、新建和归档；归档和旧 default 的只读预览也经同一守卫。文件夹或会话移动由 Runtime 同步处理磁盘与 Pi 会话关联，Renderer 不接收任意绝对目标路径。三主题共用语义 token。参考图中的第三方头像及动作栏不进入产品实现。
