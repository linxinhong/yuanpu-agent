# 0003 — 原生通知不纳入当前验收

状态：已决定（2026-09-23）；2026-09-25 更新：用户确认当前不需要提醒，移除原定的提醒界面与签名版通知验收任务。个人助手的主路径是单人企业微信私聊、定时主动投递和 App 内查看结果。

## 决策

TASK-019 只验收 IM 与调度组合；TASK-020 只交付连接、定时任务与结果管理；TASK-021 的完整旅程通过 App 内任务列表、运行详情和会话导航查看结果。系统通知展示、点击及提醒偏好不属于当前产品验收范围，也没有后续待办卡；它们不是前述卡片或后续 IM 适配的前置依赖。

已有通知实现、状态字段、测试和 TASK-019 的 V19-07 历史观测保留；移除任务卡不等于删除或关闭现有通知代码，也不将 `submitted`、开发版 `failed_event` 或用户“没看到通知”改写成签名版通过或签名版产品故障。当前没有可用 macOS 签名证书，签名版通知的实际展示与点击仍未验证；如未来重新纳入产品范围，须重新定义验收。发布签名与其他平台证据仍须如实记录，不因通知退出当前范围而自动豁免。
