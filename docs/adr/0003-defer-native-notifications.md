状态：已决定（2026-09-23）。用户要求先忽略通知功能，后续再处理；当前个人助手的主路径是单人企业微信私聊、定时主动投递和 App 内查看结果。

## 决策

TASK-019 只验收 IM 与调度组合；TASK-020 只交付连接、定时任务与结果管理；TASK-021 的完整旅程通过 App 内任务列表、运行详情和会话导航查看结果。三张卡不再以系统通知展示、点击或提醒偏好作为完成条件。TASK-029 单独承接提醒界面、有效签名版 macOS 原生通知展示与点击验收，不作为前述卡片或后续 IM 适配的前置依赖。

已有通知实现、状态字段、测试和 TASK-019 的 V19-07 历史观测保留；本决策不关闭通知，也不将 `submitted`、开发版 `failed_event` 或用户“没看到通知”改写成签名版通过或签名版产品故障。当前没有可用 macOS 签名证书，因此 TASK-029 只能等待相应验收环境。发布签名与其他平台证据仍须如实记录，不因暂缓通知自动豁免。
