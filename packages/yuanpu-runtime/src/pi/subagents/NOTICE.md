# pi-subagents attribution

Yuanpu's built-in subagent profiles and delegation design are adapted from
[nicobailon/pi-subagents](https://github.com/nicobailon/pi-subagents), version 0.71.0,
commit `2e9c51bada2da6a9ba73b6973e1545a9afa0d057` (MIT, Copyright 2026 Nico Bailon).
The upstream license is preserved in `LICENSE` beside this file.

The manager, SDK runner and tool adapter are Yuanpu-native implementations.
This is not an installation or full vendoring of the upstream Pi extension.
See `docs/pi-subagents.md` for supported behavior and compatibility boundaries.
