# Follow Up

Use current ledger items and their last verified source revisions. A due date is meaningful only when it came from the user or another trusted source. If a deadline is near or an unresolved dependency changed, propose one clear check or next action with its record ID and evidence. Mark it as a candidate and explain what remains unknown.

Do not turn quiet periods into proof of completion. Do not duplicate an unchanged candidate on each daily check. Do not send messages, write into Work conversations, start a delegated task or change task status. The Worker enforces cooldown, foreground priority, budget and App lifecycle; the later suggestion service decides whether any candidate reaches the user.
